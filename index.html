About the workshop

Verdict Test Shop is a stand-in storefront. It is built so an uptime monitor can learn a normal page: a title, navigation, a main column with headings and paragraphs, a short form, a logo image, a footer, one stylesheet and one same-site script.

When the shop is healthy, this page should look the same on every check. When we are testing a broken state, the same URL may redirect to sign-in, show a maintenance note, serve an error message, drop the script, or return an almost empty body.

Shipping is usually two to five working days within the UK, a little longer for the rest of Europe. We pack each order ourselves, include a handwritten note, and email a tracking link once the parcel has left the studio.
